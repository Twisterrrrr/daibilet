# Блок Cond Данные
0BreadcrumbsвсегдаpagePayload
1HeroвсегдаheroImageUrl, seoH1/title, shortDescription, stats, share, AddToDayRoute
2Anchor navесли есть афиша#venue-program, #about, #faq
3VenueAdmissionBlockfinance productsAdmissionProduct[]
4«Ближайшие события»sessionsпервые 4 слота
5STOP / nearby экскурсииstopEvents | nearbyEventsсвязи с каталогом экскурсий
6Афиша и билеты (VenueProgramBlock)sessionsdate chips + groups
7«О месте»descriptionтекст (без highlights chips)
8FAQвсегда (хардкод)3 общих вопроса, не per-venue
9Похожие площадкиrelatedVenuesдо 4
10Sidebar logistics + mapaddress/metro/wayToFindVenueLogisticsBlock + OSM
-Mobile stickymobileCTA

Поля Venue (релевантные контенту)

  • title, description, shortDescription, heroImageUrl
  • address, lat/lng, metroStation
  • wayToFind, parkingInfo, hookFact - наши editorial-поля; в SPBBOATS seed-venues их нет
  • kind, pageStatus, SEO (seoH1/Title/Description, canonicalPath)
  • Нет: highlights[], faq[], features[], openingHours Json, venueTemplateData, phone, website как колонки Venue
Часы для части slug (в т.ч. moscow-muzey-garazh) - hardcode в venue-opening-hours.ts, не в БД.
