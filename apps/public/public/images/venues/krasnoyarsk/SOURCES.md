# Krasnoyarsk image source notes

Updated 2026-11-02. Dated asset variants are referenced from `apps/web/src/lib/city-place-images-data.ts`. Each asset has a 1536x1024 main image, 960x640 card image, and 480x320 thumbnail.

## Generated images

- `dyadya-yasha-i-stazher-r20261102`: generated with OpenAI ImageGen from a documentary photograph of the Krasnoyarsk sculpture. The result includes both Uncle Yasha and the trainee, plus the manhole, in one frame. Reference: [Wikimedia Commons category, Monuments and memorials in Krasnoyarsk](https://commons.wikimedia.org/wiki/Category:Monuments_and_memorials_in_Krasnoyarsk).
- `pamyatnik-astafievu-r20261102`: generated with OpenAI ImageGen from [Astafiyev.JPG on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Astafiyev.JPG), a public-domain photograph by Kuznetsov. The generated frame depicts the actual full-length standing statue and its granite pedestal.
- `belaya-rotonda-r20261102`: generated with OpenAI ImageGen from a reference photograph of Krasnoyarsk's Pushkin and Goncharova rotunda. The generated frame shows both figures within the pavilion; it is not a waterfront gazebo.
- `dom-muzey-viktora-astafeva-r20261102`: generated with OpenAI ImageGen to replace a collage with a single clean exterior view of the Astafyev house museum. This is a generated illustrative image.
