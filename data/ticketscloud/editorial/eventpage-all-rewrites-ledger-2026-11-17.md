# Реестр редакционных рерайтов EventPage

Реестр считает **уникальные EventPage**, а не сеансы. Гастрольные страницы включены в ту же таблицу и помечены в колонке «Тип редакционной страницы». Если синк добавляет слоты или новые Event ID к существующей странице, обновляется строка этой EventPage — новая строка рерайта не создаётся.

## Сводка

| Показатель | Значение |
| --- | ---: |
| Уникальных EventPage с редакционным текстом | 1532 |
| READY + indexable | 1330 |
| READY + noindex | 202 |
| Гастрольных EventPage в общем реестре | 485 |
| Известных уникальных связанных Event ID в сохранённых списках | 16771 |
| Текущих связей EventPage ↔ Event по последним доступным числам | 16947 |
| Страниц, где сохранённый список ID требует обновления | 12 |

## Что учтено

- Lifecycle-снимок 16 ноября: 1205 страниц с активным редакционным текстом; статусы и количество связей обновлены по этому снимку.
- 90 новогодних EventPage, применённых 16 ноября.
- 90 страниц из батчей 01–03 от 17 ноября.
- Ещё 150 страниц из следующего набора 5×30. Между двумя наборами от 17 ноября **3 EventPage пересекались** и посчитаны один раз.
- Все 485 страниц гастрольной редакционной кампании находятся в общем списке и имеют явную метку «Гастрольная».

Синк изменил число связанных Event ID у **12 существующих страниц**: у 10 число выросло, у 2 снизилось; чистая разница — **+176 связей**. Это как раз показывает, почему нужен реестр на уровне EventPage: слоты и Event ID могут меняться без появления нового текста. Сохранённый lifecycle tracker не содержит сами новые/удалённые ID, поэтому эти 12 строк отмечены и вынесены в [отдельную таблицу дельт](eventpage-sync-delta-2026-11-16.csv). Известные списки ID не подменял предположениями.

## Ограничения сверки

Для исторических страниц использованы production-снимки, а не новый SQL-запрос: полный lifecycle-снимок датирован 16 ноября 2026, 15:39 МСК. Для последних 150 страниц есть postflight 17 ноября в 09:43 UTC. Статусы в реестре — последние подтверждённые сохранёнными отчётами. Проверки Text.ru и Content-Watch в него не входят.

Полная таблица: [CSV-реестр](eventpage-all-rewrites-ledger-2026-11-17.csv). В ней есть EventPage ID, URL, город, список известных Event ID, статус индексации, пакет рерайта, слоты/продажи и дата снимка.
