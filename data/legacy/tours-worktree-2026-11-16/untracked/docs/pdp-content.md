# Редакционный контент PDP

Новый UX пока не включён. Админка сохраняет редакционный документ отдельно от текущего публичного шаблона. Контент площадки доступен в карточке площадки, контент события — во вкладке «Контент» события.

## Сценарии

| Сценарий | Назначение |
| --- | --- |
| `museum` | музей, выставочный комплекс |
| `theater` | театр и репертуарная площадка |
| `concert_hall` | концертный зал, филармония |
| `club` | клуб и ночная площадка |
| `pier` | причал и водные маршруты |
| `landmark` | архитектура, памятник, отдельная достопримечательность |
| `nature` | парк, природный объект, маршрут |
| `urban_area` | район, улица, площадь, набережная, кластер |
| `food` | ресторан, кафе, гастропространство |
| `attraction` | зоопарк, океанариум, аттракцион |
| `transport` | вокзал, канатная дорога, фуникулёр |
| `park` | крупный парк с входными билетами, картой и прокатом |
| `space` | большое городское пространство с точками внутри |
| `religion` | храм, монастырь, религиозное место |
| `sport` | спортивная площадка или активность |
| `venue` | другая площадка |
| `event` | событие |

Список секций каждого сценария хранится в `apps/backend/src/pdp-documents.js` и отдаётся через `GET /api/admin/pdp/variants`. Смена сценария в редакторе сохраняет общие секции и заменяет остальные; перед сменой нужно сохранить отдельную копию нужных текстов.

## Модель контента

`PdpDocument` связан ровно с одной площадкой или одним событием. Поля: `variant`, `status` (`DRAFT`, `REVIEW`, `READY`), `content`, `version`, даты создания и изменения. `content` включает:

- `summary` — краткую редакционную подводку;
- `conversion` — сценарий покупки/бронирования, главное действие, необязательная подпись и привязка к событию или внешнему бронированию;
- `gallery` — фото с подписью, альтернативным текстом и авторством;
- `facts` — краткие факты с источником и датой проверки;
- `sections` — разделы сценария, каждый с текстом и повторяемыми элементами; у элемента могут быть параметры `details`;
- `sources` — список использованных источников и дат проверки.

Цены, наличие билетов, сеансы и отправления не копируются в редакционный документ: их источником остаются события, офферы и расписание. Контент может быть гораздо богаче текущей публичной страницы; позднее новый UX сможет читать его без повторного написания текстов.

Макеты храма, спортивной площадки и другой площадки уточняют соответствующие сценарии: для храма предусмотрен раздел билетов, для спортивной площадки — зоны, оборудование и ближайшие события, для другой площадки — услуги. В `upcoming_events` хранится только постоянный редакционный контекст; реальные матчи, даты и билеты выводятся из событий и сеансов.

## CTA и путь к покупке

В `conversion.mode` доступны `none`, `admission`, `events`, `departures`, `reservation`, `tours`, `hybrid`. В `primaryAction` — `none`, `buy_ticket`, `view_events`, `view_departures`, `book_table`, `view_tours`. Hero CTA, виджет и мобильный CTA должны использовать одно и то же действие. Для прямой покупки через Дайбилет можно указать `targetEventId`; `externalUrl` допускает проверенную официальную страницу покупки или бронирования, если у нас нет предложения. Подпись CTA должна ясно указывать внешний сайт. Цена и наличие приходят только из активного предложения и не пишутся вручную в редакционном документе. Без рабочего пути покупки CTA скрывается. Текст из приложенной карты DeepSeek принят как дизайн-ориентир, а не как автоматическое правило выбора шаблона.

## Подготовка контента через Cline

Для массовой подготовки Cline может формировать JSON того же формата, который сохраняет админка. Редактор поддерживает импорт и экспорт JSON; после применения JSON нужно отдельно нажать «Сохранить PDP». Ручная проверка остаётся перед статусом `READY`. Для записи через API используются `PUT /api/admin/pdp/venues/:id` и `PUT /api/admin/pdp/events/:id`; чтение — те же URL через `GET`. Не подставляйте текст макетов, демонстрационные отзывы, вычисленные в HTML даты или цены как реальные сведения.

Пример документа для музея:

```json
{
  "variant": "museum",
  "status": "DRAFT",
  "content": {
    "summary": "Краткое введение",
    "conversion": { "mode": "admission", "primaryAction": "buy_ticket", "label": "Купить билет", "targetEventId": "", "externalUrl": "" },
    "gallery": [],
    "facts": [{ "label": "Адрес входа", "value": "Проверенный адрес", "sourceUrl": "https://example.org/visit", "verifiedAt": "2026-10-21" }],
    "sections": [{ "id": "about", "kind": "about", "title": "О музее", "body": "Проверенный редакционный текст", "items": [] }],
    "sources": [{ "title": "Официальная страница посещения", "url": "https://example.org/visit", "checkedAt": "2026-10-21" }]
  }
}
```

Перед использованием требуется миграция `20261021120000_pdp_documents`.
