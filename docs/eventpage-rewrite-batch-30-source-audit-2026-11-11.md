## Перед написанием

1. В первую очередь сверить продукты с разными версиями маршрута и продолжительности: электросудно, джаз и диско на борту.
2. Сверить локальные сеансы для цирков и «Щелкунчика»; в текстах не заменять данные из продажи сторонним расписанием.
3. Для «Звезды», WIRES, Маквалы, PESHTA и «В объятиях дождя» запросить у организатора факты, если нужен длинный описательный текст. Если фактов не появится, написать только подтверждаемое ядро и не дополнять его выдуманной программой.
4. Для повторных сеансов готовить общий проверенный основной текст, а практические сведения сверять для каждого EventPage отдельно. Связи EventPage ↔ Event ID не менять.
