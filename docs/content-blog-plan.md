# Контент-план блога + еженедельный дайджест

**Обновлено:** 2026-07-19

## 5 новых заголовков (готовы к написанию)

1. **Что посмотреть в Москве на выходных: 12 событий с билетами онлайн**  
   SEO: коммерческий + локальный; ссылки на лендинги/карточки с покупкой.

2. **Речные прогулки по Москве: как выбрать маршрут и не переплатить**  
   SEO: Teplohod-кластер; сравнение длительности/причалов + CTA в каталог.

3. **Выставки и иммерсивные шоу: гид по билетам без очередей**  
   SEO: TC-кластер «выставки»; чеклист готовности карточки (виджет, цена, дата).

4. **Семейный выход: куда сходить с детьми — афиша с ценами от**  
   SEO: family intent; фильтр по тегам/подкатегориям + 8–10 карточек.

5. **Как купить билет на Дайбилете: виджеты Ticketscloud и Teplohod без лишнего аккаунта**  
   Trust/help гибрид; снижает страх перед внешней оплатой, усиливает бренд в SERP.

Статус черновиков: создать в Admin → Блог со статусом «На проверке», публиковать после правки редактора.

## Еженедельный дайджест по новым событиям каталога

### Цель
Раз в неделю автоматически собирать «что появилось в афише» → черновик статьи в `Article` (status=`review`), редактор правит и публикует.

### Не делать
- Полный auto-publish без человека (риск SEO-мусора и дублей).
- Email-парсинг билетов как источник контента.

### MVP-контур (предложение реализации)

| Шаг | Что |
|-----|-----|
| 1 | Cron вс 07:00: `scripts/blog-weekly-digest.js` |
| 2 | SQL: события с `createdAt` за 7 дней, `purchaseReady`, цена ≥100₽, есть будущий сеанс; группировка как в public catalog |
| 3 | Топ-15 по городам (Москва/СПб + 1–2 региона), с ссылками `/events/{slug}` |
| 4 | Markdown/HTML черновик: H1 «Афиша недели: N новых событий (ДД–ДД месяц)», intro, списки по городам |
| 5 | `INSERT`/`upsert` Article: `slug=afisha-nedeli-YYYY-MM-DD`, status=`review`, isIndexable=false до публикации |
| 6 | Опционально: Telegram/email редактору «черновик готов» |

### Критерии отбора (чтобы не лить весь импорт)
- Есть виджет/покупка
- Цена отображаемая ≥ 100 ₽
- Есть будущий сеанс
- Не дублировать slug прошлой недели
- Лимит 15–20 карточек; остальное — «ещё в каталоге»

### Следующий шаг разработки
После подтверждения — скрипт + cron + одна пробная генерация в review без публикации.
