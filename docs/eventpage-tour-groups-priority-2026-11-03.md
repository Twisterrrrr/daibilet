## Особые решения и группы без подтверждения

- `Открытый микрофон` (11 Event ID) — общий формат вечера, но не обязательно одно шоу/тур.
- Группы с одинаковым артистом, но разными названиями программ — отдельные tourGroup до отдельного подтверждения. В частности, «Мегамозг — презентация альбома» и «Мегамозг» остаются разными.

## Технический gap

В текущем production snapshot самих EventPage пока 0. В рабочей ветке добавляются Prisma `EventTourGroup`/`EventPage.tourGroupId`, административное назначение связи и публичный DTO переходов только между опубликованными локальными страницами с актуальным предложением. До миграции схемы, создания EventPage и проверки маршрутов переключатель городов на production не появится.

## Следующий безопасный пакет

1. Сначала создать локальные draft EventPage для однозначных saleable Event ID, не публикуя и не меняя URL.
2. Подтвердить группы первой волны по исходному названию программы/описанию и поставщику.
3. После проверки и выкладки миграции добавить/назначить подтверждённые группы; API возвращает только другие опубликованные локальные PDP группы с актуальной продажей.
4. Назначать подтверждённые группы, затем проверять переходы по каждому городу. Никаких объединённых страниц или межгородских canonical.
