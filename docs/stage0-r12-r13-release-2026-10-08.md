## Дополнение: переключение web и TAU

Прогон crawler [37745820584](https://github.com/Twisterrrrr/daibilet/actions/runs/37745820584)
обнаружил один настоящий Googlebot 502 в 07:40:38 UTC во время деплоя.
Nginx получил `connection refused` от 127.0.0.1:3001 после остановки web.
История ошибок не очищалась. В PR [17](https://github.com/Twisterrrrr/daibilet/pull/17)
добавлен прогретый резервный процесс на 3002: nginx переключается до остановки
основного процесса, проверяет основной процесс после замены сборки и возвращает
трафик только после readiness. Старые nginx workers дожидаются завершения запросов.
Повторный своп действующей сборки `c18b972` завершился успешно:
245 запросов к публичному robots.txt дали HTTP 200, ошибок не было.

По запросу владельца обновлены описание вечеринки Halloween и TAU, адрес,
метро, телефон, hookFact и wayToFind. Исходные записи сохранены в закрытых
backup-файлах на MSK. `Venue.descriptionOverridden=true` защищает текст от
импорта; текст события хранится в EventOverride. Дата источника и минимум
цены подтверждены: 31.10.2026 23:30 MSK и 1090 ₽. Категории билетов находятся
в штатном блоке покупки; платёжные продукты источника не изменялись. Инвалидация backend/Next cache
выполнена; дополнен JSON-LD концертных площадок телефоном и типом
PerformingArtsTheater (17 локальных тестов прошли).

Полный обход `sitemaps/venues.xml` 08.10 проверил 339 URL. У 338 сразу
подтверждены HTTP 200, собственный canonical и отсутствие noindex/редиректа.
Один запрос к `/locations/admiralteiskaya-nab-10-45` прервался локальной
ошибкой DNS; отдельная повторная проверка дала HTTP 200, `index, follow`
и собственный canonical. Итого все 339 URL проверены, noindex в карте — 0.
Web typecheck исправлен и стал обязательным CI gate.

По уточнению владельца описание события сокращено до трёх абзацев и двух

## Финальная проверка переключения

`ddf4361a`: reload nginx завершался раньше, чем старые workers переходили
