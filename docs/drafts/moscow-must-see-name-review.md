# name_review: похожее имя, >50 м (ручной expand vs insert)

Источник правды = **hub**. Дамп не создаёт вторую карточку при expand.

**Правило:** dist &lt; ~100 м или тот же комплекс → **expand** (берём hub coords).  
Отдельный POI внутри крупного хаба (музей на ВДНХ) → **insert**.  
Оффсет дампа &gt;300 м при том же имени → **expand** + поправить lat/lng дампа на hub (не insert).
