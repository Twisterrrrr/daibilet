## Две ошибки, которые стоит помнить

**1. Гипотеза об утечке стенда была неверна.** Префиксы `dk-`, `klub-`, `bar-`,
`stage-` в слагах выглядят как тестовые фикстуры, но проверка по БД показала:
`stage-standup-club-krasnyi-zal` — реальная площадка Ticketscloud с 236
событиями, из 463 «подозрительных» 460 связаны с TC. Подтверждена одна
служебная — `phase-g-test-museum` от финансового smoke-скрипта, вне sitemap.

Вывод был сделан из внешнего сходства без проверки. Стоило одного запроса.

**2. API `/api/public/venues` игнорирует `offset`.** `offset=0` и `offset=5000`
возвращают одну и ту же первую страницу. Любой подсчёт площадок через пагинацию
этого API даёт дубликаты. Считать только из БД.
