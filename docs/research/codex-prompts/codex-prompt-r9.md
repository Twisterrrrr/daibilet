## Задача 1 — тиры по ВСЕМ 4 304

Тир — по готовности контента, **не** по наличию событий и **не** по хабу.

| Tier | Критерий |
|---|---|
| TIER1 | описание ≥120 симв. + адрес + фото |
| TIER2 | описание есть, фото или адрес неполны |
| TIER3 | адрес есть, описания нет — нужен текст |
| HOLD | нет ни описания, ни адреса — сначала данные, потом текст |

`HOLD` — отдельным списком: текстом не чинится, нет сырья.

## Задача 2 — локации по своим правилам

`OUTDOOR_LOCATION` (242) и `MEETING_POINT` (342) тирировать отдельно. Для них
важны **координаты, hookFact, wayToFind**, а не описание с афишей.

Отдельная таблица: сколько локаций каждого тира, и сколько пригодно как
**точки маршрута** (есть координаты + hookFact или wayToFind) — это вход
в задачу про «Мой день».

## Задача 3 — тиры по городам, с учётом хабов

Ключевое отличие от прошлых постановок: **хабов 31 из 343**.

| Tier городов | Критерий |
|---|---|
| TIER1 | хаб есть (`hasPack` или `affiche`) + есть площадки TIER1/2 |
| TIER2 | крупный город, хаба нет, но площадки есть — контент опережает хаб |
| TIER3 | остальные |

Порядок: **сначала 31 хаб** (страницы уже индексируются, эффект быстрый),
потом крупные без хаба. Не писать контент под 243 города без хабов — он не
попадёт в карту.

Отдельно: доля HOLD по городам. Город с 40 площадками, из которых 35 HOLD,
получает контент позже, чем город с 10 площадками, из которых 8 TIER1.
