повторять.

### Шаг 2. Отдаёт ли API новое поле

```bash
curl -s "https://daibilet.ru/api/public/venues?limit=3" | grep -o futureSessionCount
```

- **есть** → код применён, проблема только в кэше → шаг 3
- **нет** → процесс бэкенда держит старые модули (запуск через `tsx` из

- **Не откатывать `8b7d4be5c`.** Фикс инертен, прод стабилен, откат вернёт 930

- **Не публиковать числа по карте, пока не сброшен кэш.**
