## Известная проблема в данных

**`gosudarstvennyi-ermitazh` — это Эрмитажный театр** (`kind = CONCERT_HALL`,
39 событий, Дворцовая наб. 34). Но в `shortDescription` у него лежит текст
музея: «Один из величайших и крупнейших художественных музеев мира…». **Запись
правильная, описание — чужое.** Театр физически соединён с Зимним дворцом
крытым переходом, поэтому адрес совпадает.
