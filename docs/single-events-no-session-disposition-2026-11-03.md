## Итоговая группировка

- 24 Event ID остаются в каталоге как исходные записи; ничего не удалять.
- Кандидатная группировка даёт 20 EventPage: четыре дневных выпускных объединяются в одну страницу, два Arbat Hall — в одну; остальные остаются отдельными.
- Все 15 записей выпускных и московских круизов ко Дню города относятся к завершившимся мероприятиям 2026 года. День знаний также относится к завершившемуся выпуску 2026 года.
- Три декабрьских корпоратива — будущие события, не перенаправлять.
- Для четырёх постоянных маршрутов и концерта без подтверждённой даты отсутствие `EventSession` означает `noindex,follow`, но не 404 и не redirect.
- Гастрольных связей `tourGroupId` в этой выборке нет: все записи локальны для Москвы, а повторение темы праздника не является гастролью.

## Порядок применения

1. Создать/проверить стабильные EventPage по кандидатным группам и явно прикрепить исходные Event ID.
2. Проверить, что каждая целевая страница возвращает HTTP 200 и показывает корректный текст/источник покупки.
3. Только после этого добавить 301 для старых адресов прошедших страниц на соответствующую EventPage. Будущие декабрьские события и устойчивые маршруты не перенаправлять.
4. Для страниц без сеансов выставить серверный `noindex,follow` и убрать их из sitemap; после появления продаваемого расписания пересчитать индексируемость.

До применения этих шагов production не менялся.
