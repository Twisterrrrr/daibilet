# SEO-аудит daibilet.ru - вердикт 2026-09-02

**Статус:** рабочий черновик для owner / маркетинг  
**Цель:** что мешает расти в Яндексе/Google и что чинить в первую очередь

---

## Вердикт (коротко)

Сайт **технически живой** (200, sitemap, IndexNow, viewport, robots не режет Yandex), но рост тормозит не «отсутствие meta», а три слоя:

1. **Индекс / доверие** - мало органического трафика после прошлых переобходов; Яндекс ещё не считает сайт «мобильно-дружественным» на уровне диагностики (сводка обновляется медленно).
2. **Контентная плотность** - тонкие страницы (podborki / landings / city hubs без saleable ≥ 6) уходят в noindex или в soft-404 по смыслу.
3. **UX-сигналы** - тяжёлая главная (~690 KB HTML), пустые/ломаные блоки (карта PDP), CAPS-тайтлы от поставщиков, city gate без гео в прошлом.

Пока не закроем **мобильный флаг в Вебмастере** + **переобход ядра** + **стабильные title/H1 без CAPS**, ожидать взрывного роста не стоит.

## Что мешает расти (приоритет)

### P0 - Критично для индекса

1. **Диагностика Вебмастера: «недостаточно адаптирован под мобильные»**  
   - Viewport уже на live; checker часто зависает 20+ мин - это очередь Яндекса.  
   - Действие owner: **Проверка ответа сервера** (главная + `/events`) → через сутки **переобход** TOP URL → в диагностике «Проверить снова».  
   - Риск: пока флаг красный, мобильная выдача режется.

2. **Тонкие / noindex URL в sitemap**  
   - Landings и podborki с &lt; 6 офферов.  
   - Действие: не слать в переобход thin URL; после nightly sync переобходить только ≥ 6.

3. **Главная тяжёлая для бота** (~690 KB HTML + много JS)  
   - Риск таймаута mobile checker / медленный First Contentful для бота.  
   - Действие (код, следующий спринт): урезать SSR payload главной (меньше inline JSON / отложенные рейлы).

### P1 - Высокий (конверсия + сниппеты)

4. **CAPS-тайтлы поставщиков в выдаче и на карточках**  
   - Снижает CTR.  
   - Фикс 2026-09-02: `formatPublicTitle` на карточках и H1 PDP (только UI; meta SSR можно подключить следом).

5. **Карта на странице события - пустой белый блок**  
   - UX + косвенный quality.  
   - Фикс 2026-09-02: wait-for-size Leaflet + явная высота host + карта открыта по умолчанию.

6. **Дубли / склейки city hub vs podborki?city=**  
   - Следить canonical self на пилотах KGD/SPB (см. webmaster checklist §6).

### P2 - Средний

7. **Счётчик «N городов» на главной / футере** = destinations с событиями в public API, не «все города РФ».  
   - Донецк Ростовской области → `cityToRegion` (не standalone hub). Иностранные города в `foreignCities` отсекаются.  
   - Это не баг индекса, но путает маркетинг.

8. **Отзывы / рейтинг 4.8 при 0 отзывов** (если ещё всплывает) - не SEO-blocker, но E-E-A-T шум.

9. **Internal links** - держать TOP-15 + city hubs в переобходе; не плодить orphan landings.
