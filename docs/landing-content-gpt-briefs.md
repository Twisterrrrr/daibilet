## Общие правила тона (вставить в каждый промпт)

```
Правила текста (обязательно):
- Язык: русский, ясный, без канцелярита и без «ИИ-пафоса».
- Только обычный дефис "-" . Запрещены длинное тире "—", среднее "–", многоточия-декорации.
- Не выдумывать метрики: никаких ★4.7, "N отзывов", "продано 18500 билетов", "средний рейтинг".
- Не обещать то, чего нет в продукте (мгновенный возврат денег, гарантия разводки всех мостов и т.п.).
- Trust-формулировки только такие: билет на email после оплаты; возврат по правилам организатора; электронный вход.
- Без emoji в заголовках и chips.
- Числа цен не выдумывать - оставить плейсхолдер "{priceFrom}" если нужно.
```

## Целевой канон блоков (для ориентира GPT)

1. Hero (не писать H1 здесь - SEO отдельно)  
2. Советы (tips)  
3. Расписание (не контент GPT)  
4. Как выбрать событие (howToSteps)  
5. FAQ  
6. На что обратить внимание (checklist)  
7. Отзывы - **не генерировать**. Только реальные Review; если нет данных - секция скрыта.

## JSON shapes (paste-ready)

### Tips / ContextWidget (уже в коде)

```ts
{
  "slug": "new-year",
  "title": "Новый год: как выбрать программу",
  "lead": "1-2 предложения без метрик.",
  "chips": [
    { "label": "Ёлка", "match": "елк" },
    { "label": "Шоу", "match": "шоу" }
  ],
  "tips": [
    { "title": "Короткий заголовок", "text": "1-2 предложения практики." }
  ],
  "audience": ["Семьи с детьми", "Компании друзей"]
}
```

### FAQ

```ts
{
  "faqSubtitle": "Ответы на популярные вопросы …",
  "faq": [
    { "question": "…?", "answer": "…" }
  ]
}
```

### How to choose

```ts
{
  "howToTitle": "Как выбрать событие",
  "howToLead": "Короткий подзаголовок без рейтинга.",
  "howToSteps": [
    { "title": "Выберите дату", "text": "…" },
    { "title": "Сверьте формат", "text": "…" },
    { "title": "Проверьте площадку", "text": "…" },
    { "title": "Сравните цену", "text": "Цена от {priceFrom}. Оплата в виджете организатора." }
  ]
}
```

### Checklist («На что обратить внимание»)

```ts
{
  "checklistTitle": "На что обратить внимание",
  "checklist": [
    { "title": "…", "text": "…" }
  ]
}
```

**Запрещено в JSON:** `rating`, `stars`, `reviewsCount`, `soldCount`, `reviews[]` (отзывы не генерировать).

## Как вставлять в код (для разработчика)

| Блок | Куда |
|------|------|
| ContextWidget | `LANDING_CONTEXT_WIDGETS` в `landing-context-widgets.ts` |
| Seasonal FAQ / tips city | `seasonal-landings.ts` |
| Bridges FAQ / tips | `bridges-landing.ts` + `BridgesTonightTips` / `BridgesShipChecklist` |
| Default FAQ | `defaultLandingFaq` в `LandingPageView.client.tsx` (лучше вынести в data-файл) |
| How-to / checklist | пока в View; цель - shared data по slug |
| Reviews | **не вставлять** из GPT; ждать Review API или hide |

После вставки: hyphen-only check (`—`/`–` = fail), smoke CHPU path из таблицы owner matrix.
