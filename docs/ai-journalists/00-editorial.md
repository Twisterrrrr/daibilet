# Формат «Редакция» — общие (неавторские) статьи блога

**Обновлено:** 2026-07-19  
**authorId:** `editorial` · **authorName:** `Редакция` (или `null` в UI — без вымышленного byline)

Это **не** колонка ИИ-журналиста. Канон Макса / Анны / Елены и др. сюда **не** переносить: без обязательных приветствий («Хей, читатели!» и др.) и без persona-структуры «4 абзаца колонки».

## Когда брать этот формат

- Evergreen-гиды и обзоры без голоса персоны.
- Помощь в выборе формата (крыша vs теплоход, партер vs танцпол, джем vs камерный зал).
- Материалы, где важнее польза читателю, чем стиль автора.

## Правила текста

1. **Без вымышленного автора** — `authorId: editorial`, не Макс и не другие персоны.
2. **Живое вступление** — через ситуацию, знакомую читателю (ожидание, ошибка выбора, страх «не понять»).
3. **Помощь в выборе**, не каталог-перечисление событий.
4. **Честные оговорки** — шумно, поздно, тесно, ветер, погода, очередь, возрастная маркировка врёт.
5. **Цены и ссылки есть**, но **не управляют** текстом: сначала смысл, потом мягкая отсылка на `/events/{slug}`, лендинг или поиск.
6. **Короткие абзацы**, человеческая речь; сохранять `##` и списки, если они в черновике.
7. **Ясный вывод в конце** — кому какой вариант подходит.

## CTA и покупка

- 1–3 естественные ссылки на релевантные READY-события или лендинги (`/bridges-night`, каталог города).
- Shortcode `[buy slug="…" label="…"]` — 1–2 кнопки там, где есть конкретное READY событие с покупкой; иначе только ссылка на карточку.
- Не превращать статью в витрину цен.

## Связь с колонками

| Тип | authorId | Приветствие | Структура |
|-----|----------|-------------|-----------|
| Редакция | `editorial` | нет | свободная: ситуация → выбор → оговорки → вывод |
| Колонка | `max` / `anna` / … | по канону персоны | 4–5 абзацев, style guide |
