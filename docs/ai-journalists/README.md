# ИИ-журналисты блога Дайбилет

**Обновлено:** 2026-07-19  
**Статус:** персоны и style guides готовы; первый материал — по отдельному промпту темы от пользователя.

## Зачем

Пять **вымышленных** авторских **колонок-статей** (текст в блоге, не подкаст и не аудио). У каждой — устойчивая **манера / стиль письма / register**, вдохновлённые публичными образцами известных авторов и редакций (`style_prototypes`). Byline — только имена Дайбилет. Это не impersonation.

Машиночитаемый реестр: [`personas.json`](./personas.json).

## Как пользоваться (генерация статьи)

1. Пользователь даёт **промпт темы** (маршрут / событие / город).
2. Выбрать автора по fit темы + каталогу Дайбилет (см. рекомендации в каждом профиле и в [content-blog-plan.md](../content-blog-plan.md)).
3. Скормить модели: блок `## System prompt` из профиля MD + `personas.json` + фактическую афишу/цены.
4. В MD статьи — frontmatter с `authorId`, `column`, `persona` (шаблон в каждом профиле).
5. Структура заметки — **ровно 4 абзаца**, как в System prompt персоны.
6. CTA Дайбилет — **мягкий** (у Игоря — без коммерческих клише «акция/скидка»); 1–2 естественных отсылки к билетам/маршрутам.

## Дисклеймер (для публикации / футера колонки)

> Текст написан в стиле вымышленного автора колонки Дайбилет. Манера письма вдохновлена публичными образцами тревел- и культурной журналистики (`style_prototypes`); это не высказывание и не имитация конкретного человека.

## Связь с CMS

Сейчас у `Article` (Prisma) **нет** поля `author`. Минимальное расширение (позже):

- опция A: `authorId String?` + join к статическому `personas.json` / таблице `ArticleAuthor`;
- опция B: frontmatter в `content/blog/*.md` + отображение byline на `/blog/[slug]` без миграции (быстрый пилот).

См. предложение в [Project.md](../Project.md) § «ИИ-колонки блога».
