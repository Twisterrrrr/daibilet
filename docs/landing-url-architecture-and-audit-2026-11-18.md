# Канон тематических посадок и аудит URL — 18.11.2026

## Зафиксированный архитектурный принцип

Тема является основной посадочной, город — её географическим уточнением:

- `/novyj-god` — общероссийская новогодняя подборка;
- `/novyj-god/moscow` — новогодняя подборка Москвы;
- `/koncerty/moscow` — концерты Москвы, если такой городский маршрут включён для темы;
- `/teatry/kazan` — театры Казани, если маршрут поддержан каталогом и данными.

Текущие публичные адреса и их поисковую историю сохраняем. Не создаём параллельный адрес и не настраиваем редирект только ради нового интерфейса. Городские URL публикуются лишь для тем, которые разрешены маршрутной матрицей и имеют соответствующую выдачу. `/podborki/c/{city}` остаётся городским индексом подборок, а не заменой тематических URL.

Новый интерфейс каталога может менять представление и фильтры, сохраняя маршрут и его SEO-сигналы.

## Требования к внутренней перелинковке

Каждая поддерживаемая пара «тема × город» должна получать обычные HTML-ссылки:

1. С национальной страницы темы на её городские варианты.
2. С городского индекса `/podborki/c/{city}` на тематические страницы этого города.
3. С городского хаба на актуальные тематические страницы города, если они редакционно уместны и доступны.
4. Из тематически подходящих статей на соответствующую тему и город.

Смена города на тематической странице должна вести на URL той же темы для выбранного города. Ссылка должна оставаться пригодной для робота без выполнения клиентского JavaScript.

Если городская страница не поддерживается для темы, интерфейс не должен придумывать URL. Он должен оставить выбор на общем маршруте либо предложить только доступные города.

## Результат проверки на 18.11.2026

### Доступные live-сигналы

- `/podborki/c/moscow` доступна и содержит обычную HTML-ссылку «Отмечаем Новый год» с подписью «490 событий». Переход инструмента к ней разрешился в `/novyj-god/moscow`, но сама страница не загрузилась из-за таймаута.
- `/novyj-god` доступна, но её серверный HTML сейчас показывает `0 событий` и `0 программ`.
- Ранее выгруженная `/podborki` показывала для национальной карточки Нового года 475 событий. Это не эквивалентно числу доступных сеансов в интервале новогодней страницы.
- Историческая выгрузка GSC от 29.09.2026 содержит показы для `/novyj-god/saint-petersburg` (39) и `/novyj-god/rostov-on-don/` (6). Значит, географические варианты уже получали поисковые показы; эти адреса нельзя считать новыми URL без истории.
- Доступные HTML-страницы `/novyj-god/moscow`, `/novyj-god/kazan` и `/novyj-god/saint-petersburg` веб-инструмент не смог загрузить. Это не подтверждение 404.
- Прямой SSH к production сейчас завершается таймаутом во время обмена SSH-баннером; получить актуальный sitemap с сервера не удалось.

### Почему числа Нового года расходятся

Числа из каталога и карточек посадочной считают разные множества. Backend `matchCount` считает строки публичного каталога, подходящие тематическому правилу; это не число уникальных EventPage и не число сеансов в окне 24 декабря — 14 января. Web-слой дополнительно фильтрует сеансы по сезонному интервалу. Live HTML `/novyj-god` показывает ноль после такой обработки, тогда как городская подборка в `/podborki/c/moscow` показывает 490 до неё.

Точное количество уникальных EventPage с доступными сеансами внутри окна сейчас не подтверждено production-запросом. Поэтому прежние 489 и видимые 490 нельзя считать фактическим числом карточек для новогоднего интервала.

### Кодовые и визуальные сигналы перелинковки

- Генератор `landingCategoryHref` строит тему первой и город вторым сегментом для разрешённых мультилендингов.
- Переключатель города на тематической странице рендерит `<a href>` к адресам той же темы.
- Городской каталог `/podborki/c/{city}` рендерит `<a>` на подборки с текущим городом; live-ссылка Нового года ведёт на `/novyj-god/moscow`.
- Национальный `/podborki` ведёт на национальный URL темы, а не перечисляет все её города.
- В конфигурации направлений московского хаба сейчас нет `new-year`; хаб ведёт в общий городской индекс подборок. Прямую ссылку Москва → `/novyj-god/moscow` следует считать отсутствующей до включения темы в редакционные направления.
- Страница статьи имеет общий переход в `/podborki`; прямые ссылки статья → тема × город зависят от конкретной статьи и этим аудитом не подтверждены.

1. Получить полный перечень 13 URL и проверить для каждого статус, canonical, robots, число карточек и доступных сеансов, sitemap и сезонную причину.
2. Повторить live-проверку sitemap после восстановления SSH, сверив каждый URL с реально отданными метаданными, а не только с кодовой логикой.
3. Для `/novyj-god/{city}` и остальных подтверждённых пар проверить HTTP 200, self-canonical, robots и точное число уникальных EventPage/сеансов в сезонном окне.
4. Проверить серверный HTML ссылок от темы, городского индекса, городских хабов и тематических статей; отдельно отметить существующие и отсутствующие рёбра.
5. До завершения сверки не менять порог индексации, сезонную политику, URL, редиректы и состав sitemap.
