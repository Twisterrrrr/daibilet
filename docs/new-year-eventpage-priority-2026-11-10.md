# Новогодние события: очередь рерайтов и EventPage

Снимок production-каталога собран read-only через SSH 10 ноября 2026 года.

## Границы выборки

В очередь включены события со статусом `READY` или `REVIEW`, действующим предложением и хотя бы одним активным будущим сеансом с 1 декабря 2026 года по 31 января 2027 года. Дополнительно в названии события должно быть явное сезонное указание: Новый год, Рождество, ёлка, Дед Мороз, Санта, Щелкунчик и близкие формулировки.

Это не включает зимние события, где сезонность упомянута только в описании. Их можно добавить отдельным проходом после проверки этой очереди.

## Результат

- **960 Event ID** с актуальными сеансами и активными предложениями.
- **228 кандидатных групп** по точному совпадению названия, города и площадки. Такая группировка нужна только для аудита; сама по себе она не подтверждает, что события нужно объединить.
- **363 существующие EventPage**, все черновые и `noindex` на момент снимка.
- У страниц: **354 без разделов**, **4 с отмеченным активным рерайтом**, **5 с текстом, но без маркера активного рерайта**.

Сопоставление по кандидатным группам:

| Статус связей | Групп | Следующий шаг |
| --- | ---: | --- |
| Одна EventPage связана со всеми найденными Event ID | 126 | Проверить исходный материал и подготовить рерайт существующей страницы |
| В одной группе найдено несколько EventPage | 56 | Проверить разделение страниц до редактирования |
| Часть Event ID связана, часть без EventPage | 23 | Проверить точную идентичность и завершить связи |
| EventPage не найдена | 23 | Проверить идентичность, затем подготовить создание страницы |

После проверки вариантов названия и расписания обнаружены **4 дополнительные возможные серии** (21 Event ID): новогодний кавер-фест в Твери, рождественский орган в Петрикирхе, «Щелкунчик» с экскурсией по Дворцу ученых и «Научный Новый год» в Перми. Это кандидаты на повторяющиеся показы, а не готовые решения по связям. Для них сохраняю отдельную проверку; страницы с разными программами или исходниками автоматически объединять нельзя.

Из однозначно связанных пустых EventPage после этого выделено **112 групп для рерайта**: четыре пачки по 30, 30, 30 и 22 страницы. Первая пачка уже собрана по ближайшим датам показов. Ещё 11 групп требуют проверки серийной идентичности, 53 - проверки дублей EventPage, 23 - завершения связей, 23 - подтверждения идентичности до создания страницы.

Первые города по числу кандидатных групп: Санкт-Петербург - 80, Москва - 63, Тверь - 7, Новосибирск - 6, Пермь - 6, Нижний Новгород - 5, Ростов-на-Дону - 5.

## Как проходить очередь

1. Сначала существующие EventPage с однозначной связью и пустым содержимым.
2. Для каждой страницы сверить все связанные Event ID: город, площадку, программу, организатора и оригинальные описания. Одинаковые названия без совпадающих фактов не объединять.
3. Написать содержательный рерайт: минимум два абзаца, основной текст не короче оригинала, заголовки и списки сохранить, «Практическую информацию» вынести в конце отдельным списком. Практическая информация не учитывается в сравнении длины.
4. Затем разобрать 56 разделённых групп, 23 неполные связи и 23 группы без страницы. Создавать/менять связи только после проверки первичных данных.
5. Отдельно проверить 4 страницы с уже отмеченным активным рерайтом и 5 страниц с текстом без маркера, чтобы не затереть готовую работу.
