# Новогодний лендинг: SEO, фильтры и производительность - 25.11.2026

## Объём итерации

Проверены национальная, городские и региональные страницы `/novyj-god`, клиентская фильтрация, серверный HTML и географическая карта в `landings-v2.xml`. Пилот остаётся только на новогодней подборке; другие темы не затронуты.

В интерфейсе сохранены SSR первых карточек и серверная пагинация. После SSR клиент получает компактный индекс событий и фильтрует его локально: поиск, город/регион, даты, цена, формат и сортировка не должны запрашивать API повторно. URL отражает состояние фильтров. Группировка объединяет сеансы одной программы по локальной дате: сеансы одного дня остаются в одной строке расписания, разные дни остаются отдельными строками. При неоднозначной связи сохраняются отдельные исходные группы.

## Индексация и метаданные

Live-проверка 25.11.2026 до выпуска:

- В `robots.txt` указан sitemap index `/sitemap.xml`.
- В sitemap index присутствуют `/sitemaps/landings.xml` и `/sitemaps/landings-v2.xml`.
- В `landings-v2.xml` находятся 19 новогодних URL: национальная страница, города и регионы. Новогодние URL отсутствуют в старой карте, пересечений между этими картами по Новому году нет.
- Все 19 URL вернули HTTP 200, self-canonical, `robots=index, follow`, Title, description, H1 и начальные карточки в HTML ответа. Заглушки клиентской загрузки вместо выдачи не обнаружены.
- Порог индексируемости и правила canonical/robots не менялись этой итерацией. Открытые параметры фильтров остаются пользовательским состоянием; они не добавляются как отдельные индексируемые URL.

Для `/novyj-god` Title формируется как «Новый год в России: экскурсии, каникулы и праздничные программы | Дайбилет», городская версия подставляет корректную предложную форму города. Для `/novyj-god/{город}` canonical строится на каноническом slug города. H1 остаётся пользовательским заголовком новогодней подборки, отдельно от SEO Title.

Исправлен текст meta description: вместо неграмматичного «Более 461 программ» число для больших каталогов округляется вниз до сотен, например «В афише более 400 программ». При точном кратном 100 слово «более» не добавляется; при количестве меньше 100 используется точное число. Цена в description включается только при наличии реальной минимальной цены.

## Производительность

Замер локальной функции фильтрации на нормализованной выборке из 461 записи, 250 прогонов на сценарий после прогрева:

| Сценарий | Медиана | p95 |
|---|---:|---:|
| формат | 0,76 мс | 1,55 мс |
| город | 1,05 мс | 1,53 мс |
| город + формат | 0,49 мс | 0,78 мс |
| диапазон дат | 1,49 мс | 2,08 мс |
| нижняя граница цены | 0,50 мс | 0,82 мс |
| сортировка по цене | 3,07 мс | 4,05 мс |

Это время чистой клиентской операции, без сетевого ожидания и перерисовки браузера. 461 — размер входной выборки до группировки, не количество уникальных карточек. Повторяющиеся ID в источнике соответствуют слотам одной программы; код группирует расписание до формирования карточек.

Отдельный локальный `pnpm web:build` успешно завершил компиляцию и TypeScript, но на prerender получил HTTP 429 от публичного API. Это ограничение внешнего источника, а не ошибка компиляции. Workflow Deploy MSK web строит сайт с loopback-туннелем к API MSK; окончательный build-результат фиксируется по Actions перед заменой production-артефакта.
